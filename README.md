# Mike Personal Website

Blank Vite + React + TypeScript sandbox for building the site iteratively.

## Start

```sh
npm install
npm run dev
```

Run `npm run build` to verify a production build.

## GitHub and Vercel

Publish this folder to a new GitHub repository from VS Code’s Source Control view, or create an empty repository on GitHub and add its URL as the `origin` remote. Commit and push changes to save them.

In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy. Vercel detects Vite automatically; its build command is `npm run build` and output directory is `dist`.

The global skills are provided by the local Copilot environment; they remain available without copying them into this project.
